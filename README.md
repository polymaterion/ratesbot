# Telegram-бот курсов валют

Бот отправляет три курса:

- `1 USD = X RUB` — из XML-сервиса Банка России;
- `1 USD = X TMT` — задаётся администратором командой `/tmt_rate`;
- `1 TMT = X RUB` — расчёт: `USD/RUB ÷ USD/TMT`.

Курс TMT и список подписчиков хранятся в SQLite и сохраняются после перезапуска.

## Команды

- `/start` — подписаться на ежедневную рассылку;
- `/rates` — получить курсы немедленно;
- `/stop` — отключить ежедневную рассылку;
- `/help` — показать справку;
- `/tmt_rate 18` — установить курс `1 USD = 18 TMT` (только для администраторов).

После изменения курса значение применяется сразу. Курс `TMT/RUB` автоматически пересчитывается при следующем запросе или рассылке.

## Настройка администратора

Укажите Telegram ID администратора в `ADMIN_IDS` в файле `.env`. Несколько ID можно перечислить через запятую:

```dotenv
ADMIN_IDS=123456789,987654321
```

Узнать Telegram ID можно у бота [@userinfobot](https://t.me/userinfobot). Доступ к `/tmt_rate` проверяется по числовому Telegram ID отправителя.

## Установка

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\\Scripts\\Activate.ps1
```

Установите зависимости и создайте файл настроек:

```bash
pip install -r requirements.txt
cp .env.example .env
```

В Windows вместо `cp` можно скопировать `.env.example` в `.env` вручную.

Пример `.env`:

```dotenv
BOT_TOKEN=123456:ABC...
ADMIN_IDS=123456789
DAILY_TIME=09:00
TIMEZONE=Europe/Moscow
INITIAL_USD_TMT_RATE=3.5
```

`INITIAL_USD_TMT_RATE` используется только при первом создании базы данных. В дальнейшем курс изменяется командой администратора `/tmt_rate` и хранится в SQLite.

## Запуск

```bash
python bot.py
```

Откройте бота в Telegram и отправьте `/start` — чат подпишется на ежедневную рассылку. Ежедневное время задаётся в `DAILY_TIME`, часовой пояс — `Europe/Moscow`.

Бот должен постоянно работать на компьютере или сервере. При остановке процесса ежедневная отправка выполняться не будет.

## Файлы

- `bot.py` — код бота;
- `.env.example` — пример конфигурации;
- `requirements.txt` — зависимости;
- `subscribers.sqlite3` — база подписчиков и курса (создаётся автоматически, не добавляется в Git).
